Firestore Rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /products/{document=**} {
      allow read: if true;
      allow create, update, delete: if request.auth != null;
    }
  }
}

Storage Rules:

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /chill-smoke-archive/{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null
        && request.resource.size < 10 * 1024 * 1024
        && request.resource.contentType.matches('image/.*');
    }
  }
}

メモ:
- 上記は短期・仲間内向けのゆるめの設定です。
- 画像は10MB以下、image/* のみアップロード可能にしています。
- 匿名認証を使っているため、公開URLを知っている人は書き込みできる可能性があります。
- 本格運用するならGoogleログイン限定などに変更してください。
